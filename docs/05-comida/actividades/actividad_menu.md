# 📋 Actividad: Leer un menú mexicano

En esta actividad practicarás la comprensión de un menú de restaurante mexicano.

Primero revisa el menú descargable:

👉 [Abrir menú mexicano](../menu_restaurante.pdf)

---

# 🎯 Objetivo

Comprender información básica de un menú y usar expresiones útiles para pedir comida en México.

---

# 1. Observa el menú

Busca la siguiente información:

| Pregunta | Respuesta |
|---|---|
| ¿Cuánto cuestan los tacos al pastor? | |
| ¿Qué bebida cuesta $45 MXN? | |
| ¿Qué platillo tiene salsa verde? | |
| ¿Qué comida puede ser picante? | |
| ¿Qué frase usas para pedir la cuenta? | |

---

# 2. Elige tu pedido

Imagina que vas a comer con tus compañeros.

Completa:

- Entrada: ______________________
- Platillo principal: ______________________
- Bebida: ______________________
- Total aproximado: ______________________

---

# 3. Practica el diálogo

Completa el diálogo con tu pedido.

**Mesero:** Buenas tardes, ¿qué va a ordenar?  
**Tú:** Me gustaría ______________________, por favor.  
**Mesero:** Claro. ¿Algo para tomar?  
**Tú:** Sí, quiero ______________________.  
**Mesero:** ¿Desea algo más?  
**Tú:** No, gracias. ¿Me trae la cuenta, por favor?

---

# 4. Reflexión cultural

Responde brevemente:

- ¿Hay algún platillo que te gustaría probar?
- ¿Qué comida mexicana conocías antes?
- ¿Prefieres comida con picante o sin picante?
