# ✈️ Bienvenido/a a México

¡Hola!

Acabas de llegar a México para comenzar tu intercambio académico. 🇲🇽

Todo es nuevo:
- el idioma
- las expresiones
- la comida
- el transporte
- la universidad
- y la forma en que las personas se comunican.

Durante este curso aprenderás español mexicano básico mediante actividades interactivas, narrativas digitales y situaciones cotidianas reales.

---

# 🎯 ¿Qué aprenderás?

- Expresiones mexicanas frecuentes
- Vocabulario cotidiano
- Cómo pedir ayuda
- Cómo comunicarte en la universidad
- Cultura y vida diaria en México

---

# 🧩 ¿Cómo funciona el curso?

Este curso combina diferentes herramientas digitales:

| Herramienta | Uso |
|---|---|
| Twine | Narrativas interactivas |
| Ren'Py | Conversaciones y visual novel |
| Markdown | Contenido y lecciones |
| reveal.js | Presentaciones visuales |
| Pandoc | Materiales descargables |

---

# 🌮 Situaciones que practicarás

- Llegar al aeropuerto
- Pedir comida
- Hablar con mexicanos
- Resolver problemas cotidianos
- Entender expresiones comunes
- Adaptarte a la vida universitaria
