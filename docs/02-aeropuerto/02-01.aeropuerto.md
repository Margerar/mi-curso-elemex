# ✈️ Llegada al aeropuerto

Llegar a un país nuevo puede ser una experiencia emocionante, pero también puede generar nervios y problemas inesperados.

En esta actividad interactiva practicarás situaciones relacionadas con:
- pedir ayuda
- comprender instrucciones
- encontrar información
- resolver problemas cotidianos

La narrativa se desarrolla en el aeropuerto de Ciudad de México, donde deberás recuperar tu maleta utilizando español básico y expresiones frecuentes.

---

# 🎯 Objetivos

- Pedir ayuda de manera sencilla
- Comprender instrucciones básicas
- Reconocer vocabulario del aeropuerto
- Interactuar en situaciones cotidianas

---

# 🧳 Vocabulario útil

| Español | Significado |
|---|---|
| equipaje | luggage |
| maleta | suitcase |
| información | information |
| ayuda | help |
| salida | exit |
| boleto | ticket |
